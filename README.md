# 🎯 Number Guessing Game

A simple and interactive number guessing game built using **HTML, CSS, and JavaScript**.

The game generates a random number between **1 and 100**, and the player has to guess the number. After each guess, the game provides a hint indicating whether the actual number is higher or lower.

## ✨ Features

- 🎲 Random number generation between 1 and 100
- 🔢 Number input for guesses
- ⬆️ Hint when the actual number is higher
- ⬇️ Hint when the actual number is lower
- ✅ Displays a success message when the number is guessed correctly
- ⌨️ Press **Enter** to submit a guess
- 🪟 Game opens inside a floating game box
- 🌙 Modern dark-themed user interface
- 📱 Simple and responsive layout

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling and user interface
- **JavaScript** – Game logic and interaction

## 🎮 How to Play

1. Open the game.
2. Click **Start Game**.
3. Enter a number between **1 and 100**.
4. Click **Submit** or press **Enter**.
5. Follow the hints:
   - **"Number is higher"** → Try a higher number.
   - **"Number is lower"** → Try a lower number.
6. Continue until you find the correct number.
